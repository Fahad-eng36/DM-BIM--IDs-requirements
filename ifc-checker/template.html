Drop an .ifc file anywhere on this page. It is read in your browser and is not uploaded.

Unofficial pre-check built from the IDS.json rule file (schema version ) that ships with the Dubai Municipality BIM tools. It checks that required properties exist and hold a value; it does not check geometry, usage codes or the values themselves. The official QA/QC checker remains the authority. See the requirements browser for what each element needs.
